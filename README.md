# Learn Playwright Batch 2X

A small learning repository containing JavaScript examples and exercises for Playwright and core JavaScript concepts.

## Overview

This repository collects step-by-step examples and practice files organized by chapter. It's intended for self-study and demonstration of JavaScript fundamentals and Playwright usage patterns.

## Prerequisites

- Node.js (v14+ recommended)
- npm or yarn

## Install

Install dependencies (if any) in the project root:

```bash
npm install
# or
yarn install
```

## Running example files

Most files are standalone JavaScript snippets. Run them with Node.js:

```bash
node Chapter_01_Basics/01_Basic.js
```

If you add Playwright tests or scripts, install Playwright and follow its setup:

```bash
npm install -D playwright
npx playwright install
```

# VS Code Keyboard Shortcuts for Windows

This document lists common keyboard shortcuts for Visual Studio Code on Windows. These can improve your productivity when coding.

## Basic Editing
- **Ctrl + C**: Copy
- **Ctrl + V**: Paste
- **Ctrl + X**: Cut
- **Ctrl + Z**: Undo
- **Ctrl + Y**: Redo
- **Ctrl + A**: Select all
- **Ctrl + S**: Save
- **Ctrl + Shift + S**: Save as
- **Ctrl + F**: Find
- **Ctrl + H**: Replace
- **Ctrl + Shift + F**: Find in files
- **Ctrl + Shift + H**: Replace in files

## Navigation
- **Ctrl + P**: Quick open (files)
- **Ctrl + Shift + P**: Command palette
- **Ctrl + Tab**: Switch between open files
- **Ctrl + Shift + Tab**: Switch between open files (reverse)
- **Ctrl + G**: Go to line
- **Ctrl + Shift + O**: Go to symbol
- **F12**: Go to definition
- **Alt + F12**: Peek definition
- **Ctrl + Shift + F12**: Find all references

## Editor Management
- **Ctrl + /**: Toggle line comment
- **Ctrl + Shift + /**: Toggle block comment
- **Alt + Shift + Up/Down**: Copy line up/down
- **Alt + Up/Down**: Move line up/down
- **Ctrl + Shift + K**: Delete line
- **Ctrl + Enter**: Insert line below
- **Ctrl + Shift + Enter**: Insert line above
- **Alt + Shift + F**: Format document
- **Ctrl + K Ctrl + F**: Format selection

## Terminal and Debugging
- **Ctrl + `**: Toggle integrated terminal
- **Ctrl + Shift + `**: Create new terminal
- **F5**: Start debugging
- **Ctrl + F5**: Start without debugging
- **Shift + F5**: Stop debugging
- **F9**: Toggle breakpoint
- **F10**: Step over
- **F11**: Step into
- **Shift + F11**: Step out

## Window Management
- **Ctrl + Shift + N**: New window
- **Ctrl + W**: Close window
- **Ctrl + Shift + W**: Close all windows
- **Ctrl + K Ctrl + S**: Keyboard shortcuts reference
- **Ctrl + ,**: User settings
- **Ctrl + K Ctrl + T**: Color theme

## Extensions and More
- **Ctrl + Shift + X**: Extensions marketplace
- **Ctrl + Shift + P**: Command palette (alternative)
- **Ctrl + K Ctrl + R**: Reload window
- **Ctrl + Shift + I**: Developer tools

## Customizing Shortcuts
You can customize these shortcuts by going to **File > Preferences > Keyboard Shortcuts** or pressing **Ctrl + K Ctrl + S**.

For more details, check the [official VS Code documentation](https://code.visualstudio.com/docs/getstarted/keybindings).

# VS Code Keyboard Shortcuts for Mac

This document lists common keyboard shortcuts for Visual Studio Code on macOS. These can improve your productivity when coding. Note: `Cmd` is the Command key (⌘), `Opt` is Option (⌥), `Ctrl` is Control, and `Shift` is Shift.

## Basic Editing
- **Cmd + C**: Copy
- **Cmd + V**: Paste
- **Cmd + X**: Cut
- **Cmd + Z**: Undo
- **Cmd + Shift + Z**: Redo
- **Cmd + A**: Select all
- **Cmd + S**: Save
- **Cmd + Shift + S**: Save as
- **Cmd + F**: Find
- **Cmd + Opt + F**: Replace
- **Cmd + Shift + F**: Find in files
- **Cmd + Shift + H**: Replace in files

## Navigation
- **Cmd + P**: Quick open (files)
- **Cmd + Shift + P**: Command palette
- **Cmd + Tab**: Switch between open files
- **Cmd + Shift + Tab**: Switch between open files (reverse)
- **Ctrl + G**: Go to line
- **Cmd + Shift + O**: Go to symbol
- **F12**: Go to definition
- **Opt + F12**: Peek definition
- **Cmd + Shift + F12**: Find all references

## Editor Management
- **Cmd + /**: Toggle line comment
- **Cmd + Shift + /**: Toggle block comment
- **Opt + Shift + Up/Down**: Copy line up/down
- **Opt + Up/Down**: Move line up/down
- **Cmd + Shift + K**: Delete line
- **Cmd + Enter**: Insert line below
- **Cmd + Shift + Enter**: Insert line above
- **Cmd + Shift + I**: Format document
- **Cmd + K Cmd + F**: Format selection

## Terminal and Debugging
- **Ctrl + `**: Toggle integrated terminal
- **Cmd + Shift + `**: Create new terminal
- **F5**: Start debugging
- **Cmd + F5**: Start without debugging
- **Shift + F5**: Stop debugging
- **F9**: Toggle breakpoint
- **F10**: Step over
- **F11**: Step into
- **Shift + F11**: Step out

## Window Management
- **Cmd + Shift + N**: New window
- **Cmd + W**: Close window
- **Cmd + Shift + W**: Close all windows
- **Cmd + K Cmd + S**: Keyboard shortcuts reference
- **Cmd + ,**: User settings
- **Cmd + K Cmd + T**: Color theme

## Extensions and More
- **Cmd + Shift + X**: Extensions marketplace
- **Cmd + Shift + P**: Command palette (alternative)
- **Cmd + Shift + P then "reload"**: Reload window
- **Cmd + Opt + I**: Developer tools

## Customizing Shortcuts
You can customize these shortcuts by going to **Code > Preferences > Keyboard Shortcuts** or pressing **Cmd + K Cmd + S**.

For more details, check the [official VS Code documentation](https://code.visualstudio.com/docs/getstarted/keybindings).
